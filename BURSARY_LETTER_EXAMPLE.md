## 💡 Usage Tips

### **When to Generate**:
1. After approving a bursary application
2. When student requests official letter
3. For record-keeping purposes
4. Before orientation sessions

### **How to Customize**:
- Student information auto-fills
- Amount auto-assigns (UGX 1,500,000 for bursary)
- Reference number auto-generates
- Date uses current date
- Financial assessment shows if income provided

### **Printing Recommendations**:
1. Use official university letterhead
2. Print in color for best appearance
3. Use high-quality paper (80-100gsm)
4. Sign in designated areas
5. Apply official stamp
6. Keep copy for records
